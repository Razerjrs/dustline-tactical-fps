DUSTLINE — Tactical Strike: a complete, original, round-based 5v5 tactical FPS in three.js. Two teams (Vanguard vs Ember) fight on the Kestrel Yard map with two bombsites and three lanes. Rounds are won by eliminating the other team or by planting and detonating the bomb (or defusing it). Money earned each round buys weapons, grenades and Kevlar from the buy menu between rounds. Four weapons with different price, damage, accuracy and recoil, plus HE and smoke grenades. Bots on both teams navigate waypoints, use cover, peek, plant and defuse, and react to gunfire. Accuracy counts more than speed: spread, bloom and movement penalties reward disciplined fire. Runs offline from static files, with synthesized WebAudio sounds and no external assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
